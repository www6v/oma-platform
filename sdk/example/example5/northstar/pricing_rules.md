# Pricing rules — NorthStar Health

## Enterprise (annual commit)
- Platform fee: $120,000 / year
- Per-seat: $85 / user / month (minimum 200 seats)
- Year-one typical total: ~$420,000

## Flexible (monthly)
- No annual commit
- Per-seat: $110 / user / month
- Year-one typical total: ~$468,000

Discounts require VP approval above 15%.
