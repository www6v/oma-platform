## Problem Statement

OMA Console 的 session 详情页当前使用单列垂直 timeline 展示所有事件（Conversation / Timeline / Team 三 tab）。用户希望改为 Claude Console 风格的双 tab 布局：
- **Transcript** tab：按对话轮次分组，5 类事件（User / Agent / Tool / Error / System），左栏事件列表 + 右栏 detail pane
- **Debug** tab：扁平 raw event 流，按原始事件类型过滤，左栏列表 + 右栏 detail pane（带 Rendered/Raw toggle）
- Transcript detail pane 里显示 event_id 链接，点击后切到 Debug tab 并滚动高亮对应 raw event

---

## Scope Decisions (D1-D3)

| # | Decision | Choice | Rationale |
|---|----------|--------|-----------|
| D1 | Existing 3 tabs (Conversation/Timeline/Team) | **仅替换 Conversation** | Transcript + Debug 是主 tab，Timeline + Team 作为第三/第四 tab 保留 |
| D2 | HITL panel placement | **左栏事件列表底部** | 用户直接在列表里 approve/deny，不打断 flow |
| D3 | "Link to debug event" interaction | **Tab 切换 + 高亮** | Transcript detail 里点 event_id → 自动切 Debug tab + 滚动高亮 |

### Key State Lifts

| State | Lives in | Why |
|---|---|---|
| `activeTab` | `useViewMode` hook | Tab switching — lightweight, testable |
| `selectedEventId` | `useViewMode` hook | Both tabs need to know "which event is selected" |
| `selectedDebugEventId` | `useViewMode` hook | Transcript's "View in Debug" link sets this; DebugTab scrolls |
| `transcriptCategories` | TranscriptTab (local) | Only Transcript cares about category filter |
| `debugEventTypes` | DebugTab (local) | Only Debug cares about raw type filter |

### Streaming State Handling (OV2 resolution)

Live streaming overlays (`streams`, `thinkingStreams`, `toolInputStreams`, `localPending`, `pendingByEventId`) render **only inside the Transcript tab**:
- **Active turn detail pane**: shows in-flight message/thinking/tool streams as they arrive
- **Turn list**: shows "typing" indicator on the currently-running turn
- **Debug tab**: shows only canonical events (no streaming overlays — raw events are commit-only)
- **Timeline tab**: unchanged (existing behavior)
